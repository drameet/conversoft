# DenMed AI · Conversoft — demo web viewer

**Live:** https://drameet.github.io/conversoft/

Conversoft (Conversational Software) is a clinician-in-the-loop co-pilot for orthognathic virtual surgical planning: the clinician asks in plain language, Gemini chooses the planning tool and explains, the VSP engine computes every number, and the clinician approves every step.

This is a static demo viewer of one saved plan on a **public, de-identified sample CBCT**: pre-op baseline, Le Fort I and BSSO osteotomy planes, maxilla-first movements, and the intermediate and final splints (downloadable STLs). Gemini chat runs in the Conversoft desktop app and the Google Cloud version; see the demo video: https://youtu.be/tgmNOIdjxK0

Demonstration only, not a treatment plan. Clinician validation required.
